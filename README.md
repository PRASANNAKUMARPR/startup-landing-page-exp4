# Nova - Startup Landing Page

A responsive startup landing page built using HTML5, CSS3 and JavaScript.

## Features
- Responsive navigation with a mobile menu
- Hero section with call-to-action button
- About section
- Services cards
- Contact form with front-end demo feedback
- Responsive layout for mobile and desktop

## Technologies
- HTML5
- CSS3
- JavaScript

## Run locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No installation or build command is required.

## Important
The contact form is a front-end demonstration. It does not send or store messages because no backend service is connected.
